WebGPU FDTD Test Bench

Runs the AntennaSim FDTD Yee-update kernels (the same WGSL and math as the native gpu-spike test) in your browser. Open this page on a machine, and either run the jobs manually or leave it connected — Muse can then start jobs on this page remotely, at any time, and gets the results back automatically.
